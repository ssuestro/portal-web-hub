# portal-web-hub

本仓库用于归档和发布多个独立 HTML 页面。这些页面通常用于展示信息、提供工具或作为简单的前端示例，不针对任何特定域名或网站。

## 项目简介

这是一个内容存档性质的仓库，旨在集中存放各类 HTML 文件及其相关资源。每个页面均为独立单元，可直接通过浏览器打开查看。仓库本身不提供搜索、索引或动态服务功能，仅作为静态文件存储与分发的基础结构。

## 目录说明

```
.
├── pages/          # 存放所有 HTML 页面文件
├── assets/         # 公共资源（CSS、JS、图片等）
├── docs/           # 文档或说明文件（可选）
└── README.md       # 本文件
```

- `pages/`：每个子目录或文件对应一个独立页面，命名尽量反映内容用途。
- `assets/`：存放多个页面可能共用的样式、脚本或媒体文件。
- `docs/`：可放置更详细的说明文档、更新日志或使用指引。

## 页面归档说明

归档的页面遵循以下原则：

- 每个页面应自包含或明确引用 `assets/` 下的公共资源。
- 页面不依赖外部在线服务（如 CDN、API），除非在文件内显式说明。
- 文件命名清晰，避免特殊字符，建议使用英文或拼音。
- 鼓励在页面内添加简要注释或说明，便于他人理解用途。

## 维护说明

- 添加新页面时，请放入 `pages/` 目录，并更新本文件（可选）。
- 删除或修改页面时，请确保不破坏其他文件的引用关系。
- 公共资源修改需谨慎，建议保留旧版本或做好兼容。
- 本仓库不保证所有页面长期可用，维护者会尽力保持结构整洁。

## 使用方式

1. 克隆或下载本仓库。
2. 直接打开 `pages/` 下的任意 HTML 文件即可查看。
3. 也可通过本地静态服务器（如 `python -m http.server`）运行，以获得更好的资源加载体验。
